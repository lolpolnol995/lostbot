# Инструкция по запуску бота 24/7 БЕЗ включенного ПК

Ваш Telegram-бот полностью автономен и не требует работы вашего домашнего компьютера, если размещен на сервере.

---

### Вариант 1: Запуск прямо сейчас на ПК для проверки
Если вы хотите прямо сейчас протестировать бота со своего компьютера:
1. Откройте консоль в папке `lostbot_telegram`:
   ```bash
   cd d:\wyvern-dlc\lostbot_telegram
   python bot.py
   ```
2. Откройте вашего бота в Telegram: **@Lostbotik_bot** и нажмите `/start`.
3. Так как включен **режим закрытого тестирования**, бот будет отвечать **только вам (ID: 1949806346)**! Для остальных пользователей бот сообщает о техработах.
4. Отправьте кодовое слово `JuiHuy657` или `/admin` — откроется панель управления.

### Вариант 2: Запуск 24/7 на бесплатном облаке (Render.com или Railway.app)
Чтобы бот работал круглые сутки при выключенном компьютере:

#### Способ через Render.com (Бесплатно):
1. Зарегистрируйтесь на сайте [render.com](https://render.com) (можно через GitHub).
2. Создайте новый **Background Worker** (или Web Service).
3. Загрузите файлы из папки `lostbot_telegram` (или подключите ваш репозиторий).
4. В поле **Build Command** укажите:
   ```bash
   pip install -r requirements.txt
   ```
5. В поле **Start Command** укажите:
   ```bash
   python bot.py
   ```
6. Нажмите **Deploy**. Бот запустится и будет работать 24/7 в облаке!

---

### Вариант 3: Самый надежный сервер за 100–130 руб/мес (VPS: Aeza / Timeweb)
1. Купите самый дешевый Linux-сервер (Ubuntu 22.04 / 24.04).
2. Подключитесь по SSH и выполните:
   ```bash
   sudo apt update && sudo apt install -y python3 python3-pip git screen
   git clone <ваш_репозиторий>
   cd lostbot_telegram
   pip3 install -r requirements.txt
   ```
3. Запустите бота в фоновой сессии:
   ```bash
   screen -S bot
   python3 bot.py
   ```
   (Нажмите `Ctrl+A`, затем `D` чтобы свернуть сессию).
4. Бот будет работать вечно, не выключаясь даже при перезагрузках сети!
